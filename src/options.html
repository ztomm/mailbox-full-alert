Mailbox Full Alert – Settings

Measure mailbox usage and receive a warning before storage runs out.

Set up Mailbox Full Alert

Your provider does not report a usable mailbox limit to Thunderbird. Complete these steps once:

  1. Use an IMAP account and make sure Thunderbird has synchronized all mail folders.
  2. Find the total mailbox size in your provider's customer portal, help pages or webmail.
  3. Enter that size below, choose a warning level and run the first check.

Important: The measured value matches the server mailbox when all IMAP folders are synchronized. POP accounts are only suitable to a limited extent.

Avoid an unnecessarily short interval, as frequent checks use additional processing power.
